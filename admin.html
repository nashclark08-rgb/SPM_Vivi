Online Teacher Status

Requires a free Firebase Realtime Database. Enables two features: (1) teachers in online meetings can scan a QR, enter their name, and have it appear live on the display screen so parents don’t interrupt; (2) the printed parent-sheet QR becomes much smaller and more scannable, because the teacher list is fetched from Firebase instead of being squeezed into the QR itself.

Teachers scan this QR code on PTI night to set their online meeting status.

teacher.html

Setup steps:
1. Create Firebase project & Realtime Database
2. Set rules: ".read":true, ".write":true
3. Paste database URL above & Save
4. Teachers scan this QR on PTI night
5. Names appear live on the display screen
